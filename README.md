# Monte-Carlo-PSU-Valuation


### Monte Carlo Simulation for PSU Valuation

### This Python project demonstrates an illustrative Monte Carlo valuation of performance stock units (PSUs) based on relative total shareholder return (TSR).

### Methodology: Synthetic historical returns, volatility and correlation estimation, Cholesky decomposition, geometric Brownian motion, peer TSR ranking, rank-based payout multipliers, and discounted expected payoffs.

### Assumptions: Three-year performance period, five peer companies, 4% risk-free rate, zero dividend yield, and 100,000 simulations.
Output: Estimated grant-date fair value per target PSU and a 95% Monte Carlo confidence interval.Limitations: All company data and assumptions are illustrative. 

### This is an educational model, not a production-ready ASC 718 valuation. More simulations reduce sampling error but do not correct inaccurate assumptions.
